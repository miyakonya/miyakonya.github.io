# SSH的使用
本篇总结一下SSH的连接与使用，包括修改配置文件、配置密钥连接等。

## SSH介绍
SSH（Secure Shell）实际上是一种协议。它***通常用于不安全的网络环境中进行远程登录和传输文件等***。
相比与传统的Telnet、FTP等明文传输的协议，***SSH协议对于数据内容是经过非对称加密的***，保障了数据的完整性，也避免了黑客的窃取。

## SSH安装
通常，将服务器作为SSH的服务端，常用openssh工具建立SSH服务端。
在Linux中，使用下列命令安装openssh（包含客户端和服务端）：

Ubuntu/Debian：

```bash
apt install ssh
```

Centos：

```bash
yum install ssh
```

如果只想客户端/服务端，则包名为`openssh-client`/`openssh-server`。

## SSH服务端配置
刚安装的openssh还无法直接使用，需要修改配置文件：`/etc/ssh/sshd_config`。
根据实际生产环境，修改配置文件，下列是常见的配置参数（注意：修改时需要去掉参数前的`#`号）：

| 参数名 | 作用 | 参数 | 示例 | 作用 |
|:---:|:---:|:---:|:---:|:---:|
| PermitRootLogin | 是否允许root用户登录 | yes/no | PermitRootLogin no | 禁止root用户登录 |
| PubkeyAuthentication | 是否允许使用密钥验证登录 | yes/no | PubkeyAuthentication yes | 允许使用密钥登录 |
| Port | 设置监听端口，默认22 | / | Port 1444 | 在1444端口监听ssh连接 |
| PasswordAuthentication | 是否开启密码验证 | yes/no | PasswordAuthentication yes | 开启密码验证 |
| PermitEmptyPasswords | 是否允许空密码 | yes/no | PermitEmptyPasswords no | 关闭空密码 |

下列参数并未在配置文件中，但可以添加：
| 参数名 | 作用 | 参数 | 示例 | 作用 |
|:---:|:---:|:---:|:---:|:---:|
| AllowUsers | 允许登录的用户 | / | AllowUsers test test2 | 只允许test和test2用户登录 |
| DenyUsers | 禁止登录的用户 | / | DenyUsers test | 禁止test用户登录 |
| AllowGroups | 允许登录的用户组 | / | AllowGroups admin | 允许admin用户组登录 |
| DenyGroups | 禁止登录的用户组 | / | DenyGroups guide | 禁止guide用户组登录 |

> **在实际生产环境中，通常禁止root用户登录，并使用密钥登录。**
{: .prompt-tip }

这里只做测试，故允许root用户登录和开启密钥验证。

使用下列命令开启ssh服务，并添加到开启自启动：

```bash
systemctl start ssh
systemctl enable ssh
```

## SSH连接
接下来，客户端可以通过ssh连接到服务端了。使用下列命令进行连接：

```bash
ssh 用户@主机地址
```

可以用`-p`参数指定端口，默认22。
![](/assets/img/ssh/ssh1.png)

每次连接都要输入用户名密码，地址太麻烦了。在客户端中，可以修改`~/.ssh/config`文件，添加下列内容：

```text
Host myubuntu
  HostName 192.168.8.120
  User root
  Port 22
```

下次连接时，输入下列命令即可快速连接：

```bash
ssh myubuntu
```

# SSH传输文件
SSH可以安全地传输文件，使用`scp`命令即可。用法如下：
下载：

```bash
scp 用户名@主机:远程文件路径 本地保存路径
```

上传：

```bash
scp 本地文件路径 用户名@主机:远程保存的文件路径
```

如需上传/下载整个目录，需加上-r参数。

示例：
下载`/etc/passwd`文件：

```bash
scp root@192.168.8.120:/etc/passwd passwd
```
