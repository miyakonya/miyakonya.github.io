# Web安全基础-Part3-CSRF攻击

> **警告**: 本实验仅在本地授权环境中进行，请勿在未授权网络中尝试相关攻击行为。
{: .prompt-warning }

## 一、什么是CSRF(Cross-site request forgery，跨站请求伪造)攻击
CSRF是一种利用用户身份认证信息(Cookie)进行攻击的漏洞。
它的原理是：用户在登录了某个网站后，用户浏览器会带上该网站的身份认证信息(例如Cookie)，随后，用户访问恶意网站，该网站会伪造一个请求，并带上用户的身份认证信息去访问原网站进行恶意操作。

    return render_template("transfer.html")

    if "username" not in session:
        return redirect("/login")
    user_account = session["username"]

## 四、修复
目前，主流的修复方案是引入csrf_token来校验请求的用户身份。
修改一下前端代码，在`form`标签中多写一个`input`标签：
`
<!-- Flask框架的前端用的是Jinja2模板引擎，{{csrf_token}}表示csrf_token变量的值(由后端替换) -->
<input type="hidden" name="csrf_token" value="{{csrf_token}}">
`

然后在后端的session中添加csrf_token：
```py
# coding: UTF-8
# Python 3.10.6

from flask import *
from db import getCursor
import uuid

app = Flask(__name__)
app.secret_key = "123456"

@app.route("/")
def index():
    return "Hello From Flask!"

@app.route("/login", methods=["GET"])
def login_page():
    return render_template("login.html")

@app.route("/login", methods=["POST"])
def login():
    cursor = getCursor()
    username = request.form.get("username")
    password = request.form.get("password")
    sql = "SELECT * FROM users WHERE username=%s AND password=%s"
    cursor.execute(sql, (username, password))
    if cursor.fetchone():
        session["username"] = username
        # 添加token到session中
        session["csrf_token"] = uuid.uuid4().hex    # 生成一个完全随机的uuid，并获取其哈希值作为csrf_token
        return "<h1>欢迎用户{}登录</h1>".format(username)
    else:
        return "<h1>登录失败</h1>"

@app.route("/logout")
def logout():
    session.clear()
    return redirect("/login")

@app.route("/transfer", methods=["GET"])
def tf_page():
    if "username" not in session:
        return redirect("/login")
    # 把csrf_token填充到网页中
    return render_template("transfer.html", csrf_token=session["csrf_token"])

@app.route("/transfer", methods=["POST"])
def tf():
    if "username" not in session:
        return redirect("/login")
    user_account = session["username"]
    user_token = session["csrf.token"]
    to_account = request.form.get("account")
    price = request.form.get("price")
    csrf_token = request.form.get("csrf_token")
    # 对比用户csrf_token和前端给来的csrf_token
    if user_token != csrf_token or not user_token:
        return "转账失败！CSRF Token不正确！"
    return f"转账成功！从{user_account}转账{price}元到{to_account}账户"

if __name__ == "__main__":
    app.run()
```
