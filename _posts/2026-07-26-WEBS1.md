# Web安全基础-Part1-导言

本篇是web安全基础的导言，如果你将要学习web安全那么请先阅读本导言，以便于你更好的继续阅读其他文章。
请注意，本篇***只探究web漏洞的产生以及修复，不深入探究漏洞的攻击方式***，但会用最简易的攻击方式来作演示。

## 一、需要的知识
本章通过`Flask`框架构建一个小型服务器后端，来编写不安全代码来探究web漏洞的产生以及如何修复，因此***你需要一点Python基础***来阅读`Flask`代码。当然，你并不需要学习`Flask`框架，但是***你必须知道关键代码是做什么的。***
- Python基础
- HTTP
- SQL基础
- Web开发基础(HTML、CSS、JavaScript)

## 二、收录的Web漏洞
- SQL注入
- XSS攻击
- 文件上传漏洞
- CSRF攻击
- 越权漏洞(IDOR)

## 三、项目结构

```
app.py: 后端服务端代码
db.py: 连接MySql服务器
templates: 前端html文件
uploads: 文件上传存放处
```

每章的html文件会给出，不需要自己写。
