# Web安全基础-Part2-SQL注入

## 一、什么是SQL注入(SQL Injection)
SQL注入是指后端对前端传来的参数未进行校验，将恶意参数拼接到sql语句中，造成执行恶意sql语句，进而导致信息泄露等
风险。
常见的sql注入攻击方式有：
- 联合查询(Union Query)
- 布尔盲注(Boolean Blind Injection)
- 时间盲注(Time Blind Injection)
- 堆叠注入(Stacked Injection)

### 2.2 后端环境搭建

接下来写一下后端代码：
```py
# coding: UTF-8
# Python 3.10.6

from flask import *
from db import getCursor

app = Flask(__name__)

@app.route("/")
def index():
    return "Hello From Flask!"

# 如果是GET请求，则转到登录网页
@app.route("/login", methods=["GET"])
def login_page():
    return render_template("login.html")

# 接收到POST请求，开始执行登录代码
@app.route("/login", methods=["POST"])
def login():
    cursor = getCursor()    # 获取sql连接游标
    username = request.form.get("username") # 获取前端传来的用户名
    password = request.form.get("password") # 获取前端传来的密码
    # 将用户名和密码拼接到sql语句中(不安全)
    sql = "SELECT * FROM users WHERE username='{}' AND password='{}'".format(username, password)
    # 执行
    cursor.execute(sql)
    print("sql语句执行:", sql)
    if cursor.fetchone():
        return "<h1>欢迎用户{}登录</h1>".format(username)
    else:
        return "<h1>登录失败</h1>"

if __name__ == "__main__":
    app.run()
```

根据这个sql语句，我们可以判断出，在用户名后的一个单引号将username参数给闭合掉了，因此后面的数据被当成了sql语句执行，而`--`在sql中是注释符(其后要加一个空格)， 它把`--`后的代码被注释掉了。所以实际执行的sql语句为：
```sql
SELECT * FROM users WHERE username='admin';
```
由于admin用户肯定存在的，所以这条语句恒成立，绕过了密码验证，直接登录了。
冷知识：`'--+`在以前网络还不够安全的年代，称为"万能密码"。

## 四、修复
目前，主流的修复sql注入漏洞的方式为使用"参数化查询(Parameterized Query)"。但这个方法只能用于查询语句中，在`UPDATE`、`INSERT`等语句中无法使用。

在`Python`中，可以通过下列方式实现参数化查询：
```py
# 这里的占位符必须用%s，即便它是整数型
sql = "SELECT * FROM users WHERE username=%s AND password=%s"
cursor.execute(sql, (username, password))   # 如果只有一个参数，则应写为cursor.execute(sql, (username,)) 
```

在`Java`中，可以用预编译语句(Prepared Statement)，不仅能用于查询，也能用于其他sql语句：
```java
String sql = "SELECT * FROM users WHERE username=? AND password=?";
try (PreparedStatement pstmt = conn.prepareStatement(sql)) {
    pstmt.setString(1, username);
    pstmt.setString(2, password);
    ResultSet rs = pstmt.executeQuery();
}
```

在我们上面的python例子中，可以这么写：
```py
sql = "SELECT * FROM users WHERE username=%s AND password=%s"
cursor.execute(sql, (username, password))
print("sql语句执行:", sql % (username, password))
```
